# Política de seguridad

Este proyecto compila y ejecuta código recibido por HTTP sin aislamiento. Úsalo únicamente en un entorno local de confianza. No publiques el servicio mientras no tenga aislamiento de procesos, límites de recursos y separación de archivos por solicitud.

Si detectas una vulnerabilidad, usa el reporte privado de la pestaña Security de GitHub si está disponible. En otro caso, contacta al mantenedor de forma privada desde su perfil. No publiques código de explotación en un issue.
